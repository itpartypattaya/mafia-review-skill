# Расшифровка партии №N — дата

Сводная по двум диктофонам (Д1 — у ведущего, Д2 — другой конец стола). Реплика приводится
один раз; источник указан, когда реплика есть только на одной дорожке. Говорящие: «Ведущий»,
«№N Имя» — только при уверенной привязке голоса к месту, иначе «Игрок (не установлен)».
Правки — орфография, пунктуация, ослышки, артефакты; ничего не дописано и не сокращено.

| Время | Кто | Реплика |
|---|---|---|
| 00:12 | Ведущий | Начинаем игру номер два. Город засыпает. |
| 00:40 | Ведущий | Босс мафии просыпается, проверяет игрока. |

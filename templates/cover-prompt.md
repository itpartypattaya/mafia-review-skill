## Как подобрать мотивы (из хронологии, без имён и ролей в тексте картинки)

| Событие партии | Предмет / мизансцена |
|---|---|
| доктор остановил выстрел | щит с жезлом-кадуцеем, пуля застыла у щита |
| комиссар нашёл чёрные карты | лупа над картами, значок, карта с портретом сыщика |
| маньяк дошёл до конца / победа одиночки | одна фигура в луче лампы, остальные стулья пусты |
| двое выбыли в один день | два перевёрнутых стула, две карты рубашкой вверх |
| финал один на один | два игрока лицом к лицу, между ними одна карта |
| долгая партия (5+ ночей) | песочные часы / часы на стене, догоревшие свечи |
| мафия вела стол | тёмная фигура в шляпе за спинами, тень на стене |
| выведен красный по ошибке | рука, опускающая красную карту в пепельницу |
| жулик забрал карту | рука, тянущая карту из чужой стопки |
| свидетель принял карту | карта, передаваемая из рук в руки |

Правило: один главный мотив явно, один-два — намёком. Людей — столько, сколько за столом
к моменту сцены (или полный состав, если сцена — общий план).

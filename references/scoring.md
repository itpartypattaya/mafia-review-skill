# Оценки: формула клуба (scoring-v1) — читаемая версия `code/scoring.py`

Принцип: **оценку считает формула, наблюдения поставляет разбор.** Ни одна цифра не
ставится «от впечатления». Всё в тысячных (5.5 = 5500), округление half-up один раз — на
последнем шаге каждого навыка. Шкала 1.0–10.0. Пять навыков: аналитика (`analysis`),
интуиция (`intuition`), влияние (`influence`), исполнение роли (`role`), дисциплина
(`discipline`). Итог партии = среднее пяти, half-up до 0.01 (сервис считает сам).

```
score(skill) = clamp(base(skill) + delta(skill), 1.0, 10.0)
raw    = Σ sign_i × strength_i            по сигналам этого навыка
n      = число сигналов
delta  = clamp(raw × 0.5, −3.0, +3.0) × n / (n + 2)
```

Один сигнал силы 1 двигает не больше чем на ~0.17 (0.5 × 1/3); три согласных единицы —
на 0.9; десять — почти на весь коридор ±3. Шкала роудмапа (9–10 «решил партию», 7–8.5
сильно, 5–6.5 средне, 3–4.5 слабо, 1–2.5 вред) достигается только накоплением сигналов.

## 1. Базы (без модели — из листа, фактов, исхода)

`participation` — доля фаз партии, в начале которых игрок был жив (дожил до конца = 1.0;
погиб в ночь 1 при 8 фазах — 1/8).

**Дневные навыки (аналитика, интуиция, влияние):**
`5.0 + 1.0 × participation + (1.5 × participation, если его сторона победила)`.
Первоночный при победе ≈ 5.3; доживший победитель — 7.5; доживший проигравший — 6.0.

**Дисциплина:** база **8.0** («как в эталонах: 8 минус нарушения»).

**Исполнение роли** — по стартовой карте:
- мирный и роли без ночной механики (свидетель без перехода, камикадзе без активации,
  жулик без хода): `3.0 + 2.0 × participation + (1.5 × participation при победе)`;
- **комиссар:** `3.0 + 7.0 × min(1, точность)`, точность = (попадания + 0.5 × проверки
  красных) / **ночей партии** (не прожитых!). Комиссар, погибший в ночь 1 с одним
  попаданием из четырёх ночей: 3.0 + 7.0 × 0.25 = 4.75;
- **доктор:** `3.0 + 0.3 × min(лечений, 3) + 3.0 за спасённого мирного + 5.0 за
  спасённую активную роль` (за каждое остановленное попадание);
- **чёрные паритета (босс, мафия):** `3.0 + 3.5 × participation + 2.0 при победе +
  min(1.5, Σ килов: активная роль 1.0, мирный 0.5) + 1.0 за найденную боссом активную
  роль`;
- **маньяк:** `4.0 + 2.5 × participation + 3.0 при победе + min(3.0, Σ килов: чёрная
  карта 1.5, активная 1.0, мирный 0.5)`;
- **камикадзе:** стандарт + 3.0, если в ночь его гибели ушёл и маньяк;
- **жулик:** стандарт + 2.0, если карта была забрана (финальная роль ≠ стартовой);
- **оборотень:** стандарт; если стал чёрным (финальная карта паритета «чёрные») —
  считается как чёрный.

## 2. Детерминированные сигналы (считаются по листу и фактам, без мнения)

| Код | Кому | Навык | Знак/сила | Когда |
|---|---|---|---|---|
| `check_hit` | босс, комиссар | интуиция +3, аналитика +2 | проверка попала (комиссар — в чёрную карту; босс — в активную роль) |
| `heal_saved` | доктор | интуиция +3 | лечение остановило выстрел |
| `saved_active_role` | доктор | интуиция +3, аналитика +2 | спасённая карта — активная роль |
| `heal_missed` | доктор | интуиция −1 | лечение не совпало с выстрелом |
| `shot_killed` | мафия, маньяк | интуиция +1/+2/+3 | выстрел достиг цели: мирный / активная роль / (маньяк) чёрная карта |
| `pointed_at_black` | красный | аналитика +1 (+2, если цель изгнана) | обвинение/выставление/голос подтверждённого голоса в чёрную карту |
| `pointed_at_expelled` | красный / чёрный | влияние +2 | названный игрок покинул стол (у чёрного — только если это был красный) |
| `pointed_at_red` | красный | аналитика −1 (−2, если цель изгнана) | указал на красного |
| `defended_and_stayed` | любой | влияние +1 | вышел на оправдание и остался |
| `expelled_as_red` | красный | влияние −2, интуиция −1, аналитика −1, роль −2 | стол вывел красную карту |
| `survived_vote_as_black` | чёрный | влияние +1, аналитика +1 | день с изгнанием, а вывели не его (за каждый такой день) |
| `foul_removed` | любой | дисциплина −3 | удалён за фолы (единственный детерминированный сигнал дисциплины) |

Указания маньяка формула не считает (он против всех) — их оценивает разбор сигналами.
Указания засчитываются только по **подтверждённому голосу** (`speaker_seat` известен).

## 3. Сигналы разбора (то, что в конвейере даёт JUDGE)

Правила — `prompts/judge.v6.md`. Кратко:
- навыки только `analysis`, `intuition`, `influence`, `discipline` (роль — только лист);
- один поступок с основанием = один сигнал; основание — событие или заявление **самого
  игрока** с подтверждённым голосом; без основания сигнал не существует;
- `strength`: 1 — эпизод; 2 — заметный поступок (аргумент, который стол принял;
  выставление, доведённое до изгнания; точное указание на чёрного); 3 — поступок,
  решивший фазу или партию. Тройки редки: одна-две на стол;
- не дублировать то, что формула уже знает (попадания по листу, факт изгнания, дожил,
  победа) — только речь, аргументы, выставления, защита, реакция стола;
- не больше **6** сигналов на навык у одного игрока — дальше это накрутка;
- дисциплина — только реальные нарушения регламента из фактов, `negative`;
- у каждого игрока состава — запись: если наблюдений нет, пустой список сигналов и
  короткий комментарий по фактам.

## 4. Как оформить расчёт (внутренний `scores.md`, в review.md не входит)

```
№2 Марк, комиссар, дожил, сторона победила (participation 1.0)
  base: analysis 7.5, intuition 7.5, influence 7.5, role 3.0+7.0×(2/3)=7.67, discipline 8.0
  intuition: check_hit +3, check_hit +3, [судья] +2 «вскрылся вовремя» → raw 8, n 3 → delta = 3.0×0.6 = 1.8 → 9.3
  analysis:  check_hit +2, check_hit +2 → raw 4, n 2 → delta 2.0×0.5 = 1.0 → 8.5
  ...
```

## 5. Номинации — кандидаты по метрикам (`nomination_candidates`)

| Код | Кто | Вес |
|---|---|---|
| `best_checks` | комиссар с наибольшим числом чёрных карт по проверкам | 30 + 10 × попаданий |
| `key_heal` | доктор, чьё лечение остановило выстрел (активная роль — приоритет) | 45 / 30 |
| `maniac_run` | маньяк с ≥ 2 результативных выстрелов, или снял чёрную, или победил | 35 + 5 × килов (+15 победа) |
| `last_black` | чёрная карта паритета с наибольшим участием (≥ половины партии) | 25 (+15 победа, +10 дожил) |
| `table_reader` | красный, чаще других указывавший на чёрных (баланс ≥ 2) | 20 + 5 × баланс |
| `kamikaze_hit` | камикадзе, забравший маньяка | 40 |
| `survivor_win` | запасной: дожил до победы (только если кандидатов < 3) | 10 |

Один игрок — одна номинация; до трёх лучших по весу. Название — 2–4 слова, роль называть
можно («Детектив партии», «Спаситель города», «Последняя мафия»); причина — одна фраза по
метрике и фактам. Не повторять по смыслу прошлые названия (синоним — тоже повтор).

## 6. Что сервис делает с оценками дальше (для понимания, не для расчёта)

Рейтинг игрока: `B = (5.5 × 3 + Σ оценок) / (3 + n)`, рейтинг = round_half_up(B × 100),
старт 550. XP: участие 100, победа 50, номинация 30. Оценки из `review.md` идут в рейтинг
как ручные оценки ведущего — поэтому они обязаны быть у каждого игрока состава.

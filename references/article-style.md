# Форма и стиль разбора

Источник правды — `prompts/story.v6.md` (аналитика), `code/article.py` (программные
разделы и порядок), эталонные разборы владельца (24 файла telegra.ph, март–август 2026;
последний формат — 16.08.2026). Здесь — их сводка и то, чего в промте нет.

## 1. Порядок разделов в `review.md`

Первые пять — как собирает `article.assemble`, дальше — аналитика модели, затем данные.

| Раздел | Кто пишет в конвейере | Что внутри |
|---|---|---|
| `# Название` | модель | 3–7 слов про суть, образ, без даты и номера: «Маньяк забрал стол в одиночку», «Комиссар против четырёх карт» |
| лид | модель | 1–3 предложения: кто победил, на каком дне, ирония/перелом |
| `## Исход` | данные | `Победили: …` + таблица состава (контракт импорта) |
| `## Состав стола` | код | пункты «Чёрные карты: №5 Имя — босс; …», «Активные красные роли: …», «Одиночка: …», «Мирные жители: №1 Имя, №8 Имя»; при смене роли — «(стартовая карта — …)» |
| `## Ночные события` | код | по ночи один пункт: «Ночь N: босс проверяет №2 — комиссар. Мафия стреляет в №1. Маньяк стреляет в №8. Комиссар проверяет №4 — чёрная карта. Доктор лечит №1 и останавливает выстрел. Утром стол покидает №8.» Роли без хода в ночь не попадают; порядок — порядок пробуждения (босс, мафия, маньяк, нагнетатель, комиссар, доктор) |
| `## Хронология` | код + модель | `### День N — подпись` / `### Ночь N — подпись`, чередуются до финала. Под заголовком: программные факты фазы (кто на оправдании, кого вывел стол с ролью, «Стол уходит в ночь без потери карты», «За фолы удалён …», в финале «Партия окончена: победа красных/чёрных/одиночки»; ночью — ходы и «Утром стол покидают …» либо «Ночь проходит без потерь»), затем абзац-рассказ. День — 3–8 предложений, ночь — 2–4 |
| `## Что решило игру` | модель | 3–5 пунктов `- <эмодзи> кто что сделал — последствие` |
| `## Почему проиграл город` / `## Почему проиграли чёрные` / `## Почему никто не выиграл` | модель | 1–3 абзаца связной логикой от причины к следствию, не список |
| `## Лучшие ходы` | модель | 2–6 пунктов по сторонам и игрокам с тем, чем обернулись |
| `## Ошибки` | модель | 2–6 пунктов: чьи, в чём, к чему привели |
| `## Итог` | модель | 1–2 абзаца: за счёт чего победа и один урок, привязанный к решению этой партии; в эталонах последняя фраза — «Главный урок партии: …» |
| `## Оценки игроков` | данные | таблица (контракт импорта); порядок — по местам, не по рейтингу |
| `## Номинации` | данные | до трёх |

## 2. Эталон 16.08.2026 — как это выглядит у владельца

```
## 🎭 Игра №N — дата            ← лид одним предложением
## 🃏 Состав                    ← три абзаца: чёрные роли / активные красные / мирные
## 🕰 Хронология
### ☀️ День 1 — город уходит без вывода
### 🌙 Ночь 1 — комиссар сразу находит мафию
…
## ⚖️ Что решило игру          ← 5 пунктов с эмодзи 🔎 🩺 🎯 ⚔️ 🗳️
## 📊 Оценки игроков           ← «**№N Имя — 5.2/10 (5/5/5/3/8).** одно-два предложения»
## 🏅 Номинации партии         ← ровно 3: «🔎 **Название — №N Имя.** причина»
## 🏛️ Итог                     ← 2–3 предложения + «Главный урок партии: …»
```

Что взять из эталона: содержательные подписи фаз («двойной вывод босса и свидетеля»),
ночь как перечисление всех ходов по листу в порядке пробуждения плюс «Утром … покидают
игру», день как «кандидаты — голоса — кто вышел и кем вскрылся», «что решило» как
субъект + действие + последствие. Эмодзи в заголовках допустимы — импортёр их игнорирует.

Старый формат (март–май) плотнее по дням: круг речей разбирается по каждому игроку
отдельным пунктом («X выставлял A и B», «Z голосовал в Y»), упоминаются иммунитет первого
выбывшего, несострел, последнее слово. Это и есть та плотность дней, которой конвейеру не
хватает, — у тебя окна нет, делай так.

## 3. Стиль

- Короткие фразы; настоящее время в хронологии; сначала действие, потом смысл.
- Игроки — `№6 Имя`, имя из состава. В таблицах и пунктах — всегда с номером; в связном
  абзаце после первого упоминания можно по имени.
- Роли называть можно и нужно (разбор выходит после вскрытия). Но: пока партия закрытая
  (до финала) роль живого игрока не называется — в готовом разборе это не случается.
- Дословные цитаты запрещены — пересказ. Никаких «как сказал №3: „…“».
- Канцелярит-стоп-лист: «решающим фактором стала», «способствовало», «в лице», «разбор
  отмечает», «продемонстрировал», «осуществил», «данный».
- Без превосходных степеней: «феноменально», «блестяще», «катастрофа» — вычеркнуть.
- Сторона решает смысл: вывод мафии — успех города; вывод красного — успех чёрных; маньяк
  играет против всех (ему на руку и то, и другое).
- Драматическая ирония — главный приём: доктор спас чёрную карту; комиссар нашёл мафию и не
  донёс; игрок защищал того, кто убьёт его ночью; свидетель принял карту комиссара и в ту
  же ночь пошёл проверять. Ищи пересечения листа с речью и называй прямо.
- Переход роли — сильный момент, называть прямо («свидетель №3 приняла карту комиссара»).
- Мягкая формулировка — только для вывода из речи, и только этими словами: **похоже, судя
  по всему, вероятно, возможно, предположительно, по мнению**. Факты листа (роли, ходы,
  изгнания, исход) пишутся прямо, без «вероятно».
- День без заявлений: «запись этого дня не даёт деталей» — и всё.
- Не додумывать: реплики, мотивы, события. Не установленное — так и называть.

## 4. Типы предложений (для самопроверки, как в схеме статьи)

- `sheet_fact` — роли, ночные ходы, исход из листа: прямо.
- `verified_fact` — объявление ведущего из записи: прямо.
- `inferred_claim` — твоё чтение речи игрока: с хеджем.
- `opinion` — оценочное суждение, опирающееся на оценку/наблюдение: «сильнейший ход дня».
- `editorial` — связка без нового факта.

Коды проверки: `UNGROUNDED_FACT` (в тексте факт, которого нет ни в листе, ни в событиях),
`HARD_CLAIM` (вывод из речи без хеджа), `OPINION_AS_FACT`, `VERBATIM_QUOTE`, `HIDDEN_INFO`
(роль живого игрока в закрытой партии), `OTHER_GROUNDING`. Переходы ролей по своду не
считаются противоречием листу.

## 5. Чем сервис меряет качество (`cli/eval_reference.py`)

Одинаково для эталона и статьи: разделы по кодам (`roster / nights / timeline / decisive /
why_lost / best_moves / mistakes / conclusion / scores / nominations`), число и нумерация
фаз, **адресные упоминания игроков на фазу** (главная цифра), пункты «что решило игру»,
выбывшие по дням, слова. Ориентиры эталона партии 29: ~2400 слов, ~145 адресных
упоминаний, День 2 — 30 упоминаний. Не измеряется, но решает: верность фактов,
читаемость, интонация, ирония — это глазами ведущего.

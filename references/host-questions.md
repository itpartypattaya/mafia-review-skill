# Вопросы ведущему по листу — все закрыты

История: вопросы собирались по видеоинструкции (23.08.2026) и пяти фото заполненных
листов (24.08.2026); ответы ведущего получены 24.08.2026 голосовым сообщением.
Итоги вшиты в `docs/02-host-sheet-legend.md` (§6) и мастер-план (§5, §6A.1).

| ID | Вопрос | Ответ ведущего (пересказ) |
|---|---|---|
| HS-1 | Куда пишутся мирные | Столбиком под блоком ролей; строку «Мирные» не заполняет. В новом шаблоне строки «Мир 1..N» печатные — вписывает только номер и имя. |
| HS-2 | Отметка выбывшего | Зачёркивает, но нерегулярно («могу забыть… по записи игры будет понятно, кто выбыл»). Живой состав — по записи/симулятору. |
| HS-4 | Жулик забрал карту | У роли жертвы в скобках буква «Ж» («жулик стал этой картой»), строка жулика вычёркивается из списка. |
| HS-5 | Исходник бланка | Закрыт по фото: 7 колонок ДЕНЬ и 7 колонок НОЧЬ. |
| HS-7 | Цифра рядом с палочками | **Руки за выгон**: палочки — голоса выставления (30-сек речи), цифра справа — сколько рук подняли на выголосовывании. Ставит не всегда ⇒ нет цифры = `null`. |
| HS-8 | Знак «+» в клетке дня | Отдельного знака нет — «наверное, просто палочка». |
| HS-9 | Номера мест в ночных событиях | Играют по номеркам; впредь ставит номер места и в ролях, и в ночных событиях («у нас будет всё по номерам»). |

Открытым остаётся только **HS-6** (порядок пробуждения зависит от режима партии) — он
разрешается через `rule_set`, вопросов к ведущему не требует.

# mafia-game-review — разбор партии «Мафии» агентом Codex

Скилл для [OpenAI Codex](https://github.com/openai/codex), который по двум диктофонным
транскрипциям и листу ведущего делает полный разбор партии клубной «Мафии» — то же, что
платный AI-конвейер сервиса [Mafia IT Party](https://mafia.itparty.club), но на подписке
агента, без токенов Gemini:

- сводная чистая расшифровка двух дорожек (ведущий — по содержанию речи, игроки — по местам);
- хронология по дням и ночам, события ведущего, заявления игроков;
- **вопросы ведущему** по неясным местам — и остановка, пока он не ответит;
- оценки пяти навыков **по формуле клуба** (база по листу + сжатые сигналы), номинации по метрикам;
- статья в форме клуба (состав, ночи, хронология, что решило игру, ходы, итог);
- промт обложки в стиле обложек прежних разборов;
- итоговый `review.md` по контракту импорта сервиса: ведущий загружает его с баннером в
  студию партии, сервис сверяет состав с распознанным листом и публикует одной кнопкой.

Как устроено — [ARCHITECTURE.md](ARCHITECTURE.md).

## Установка

```bash
git clone https://github.com/itpartypattaya/mafia-review-skill ~/.codex/skills/mafia-game-review
```

Codex подхватывает скилл по `name`/`description` из шапки `SKILL.md`. Обновление —
`git pull` в той же папке.

## Использование

1. В папку партии положить: `transcript-1.*`, `transcript-2.*` (обычно сплошной текст
   автоматической расшифровки диктофона без таймкодов и меток говорящих), фото или
   расшифровку листа ведущего, состав A1 (`№ — имя — стартовая роль`).
2. Сказать Codex: «Разбери партию по скиллу mafia-game-review, файлы в папке …».
3. Ответить на `questions.md` — без ответов разбор дальше сверки не идёт.
4. Забрать `review.md`, `facts.md`, `transcript.md`, `banner.png` (или `cover-prompt.md`);
   загрузить `review.md` + баннер + `facts.md` + `transcript.md` в секцию «Готовый разбор»
   студии партии и нажать «Опубликовать».

| `references/rules.md` | свод правил клуба: роли, порядок ночи, переходы карт, победа, регламент дня, термины |

| `references/pipeline-and-pitfalls.md` | конвейер сервиса шаг за шагом и грабли живых прогонов |
| `references/article-style.md` | форма статьи, эталон, стиль, хеджи, чем меряется качество |
| `references/scoring.md` | формула оценок, базы по ролям, сигналы, кандидаты номинаций |
| `references/article-quality-journal.md` | журнал сравнений статей конвейера с эталонами |
| `references/review-import-contract.md` | контракт `review.md` и что сервис делает с файлом |
| `references/prompts/` | активные промты конвейера сервиса **дословно** (12 шагов) |
| `references/schemas/` | JSON-схемы ответов этих шагов |
| `references/code/` | `scoring.py`, `article.py`, `cover_brief.py`, `rating.py`, `story.py` как есть |
| `templates/` | `review.md` и `facts.md` (контракты парсера сервиса, на вымышленных именах), `questions.md`, `transcript.md`, `cover-prompt.md` |

## Откуда берётся и как обновляется

Источник правды — каталог `skills/codex/mafia-game-review/` в приватном репозитории сервиса
`itpartypattaya/mafia`; этот репозиторий — его публичная копия. Промты и расчётный код в
`references/` совпадают с активными версиями конвейера: в репозитории сервиса за этим
следят тесты (`test_skill_prompts_match_active_versions`, `test_skill_template_parses`).
При смене промтов конвейера копия обновляется вместе с ними.

## Приватность

В скилле нет записей, листов и разборов реальных партий: шаблоны — на вымышленных именах,
справочники — правила, легенда бланка и методика. Выходы скилла (`review-*/`) содержат
имена игроков — держите их вне публичных репозиториев (`.gitignore` уже исключает
`review-*/`).
